Que es ClockWise XE1E?

ClockWise XE1E es un firmware open source para crear tu propio reloj inteligente usando una matriz LED RGB de 64x64 pixeles y un microcontrolador ESP32 o ESP32-S3.

A diferencia de otros proyectos similares, ClockWise XE1E incluye un editor visual web que te permite disenar tus propias caratulas sin necesidad de programar. Simplemente arrastra elementos, ajusta colores y ve el resultado en tiempo real.

  • Instalacion en 2 minutos con el Web Flasher
  • Configuracion completa via WiFi (sin cables)
  • Funciona sin internet despues de configurar
  • Caratulas JSON editables y compartibles
  • Soporte completo en espanol

Fork mejorado de Clockwise

Este proyecto es un fork del excelente Clockwise de @jnthas, con mejoras significativas: editor visual de caratulas, caratulas nativas animadas (Mario, Pac-Man), soporte multi-WiFi, modo nocturno automatico, y muchas optimizaciones mas.
