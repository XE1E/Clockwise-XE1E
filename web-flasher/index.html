Instalar Firmware

Requisitos
  • Navegador con WebSerial (Chrome, Edge, Opera)
  • ESP32 o ESP32-S3 conectado por USB
  • Cable USB con datos (no solo carga)

Selecciona tu placa:

ESP32
DevKit V1, DOIT, etc.
ESP32-S3
DevKitC-1
Tu navegador no soporta WebSerial. Usa Chrome, Edge u Opera en escritorio. WebSerial requiere HTTPS. Accede via https://xe1e.github.io/Clockwise-XE1E/web-flasher/

Instrucciones

Conecta tu ESP32 al puerto USB
Selecciona tu placa (ESP32 o ESP32-S3)
Haz clic en "INSTALAR" y selecciona el puerto COM
Espera a que termine el flasheo (~1 min)
El reloj creara una red WiFi "ClockWise-XXXX" para configurar
Conectate a esa red y configura tu WiFi en 192.168.4.1
