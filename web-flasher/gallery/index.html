Como instalar una caratula

  1. Descarga el archivo JSON de la caratula
  2. Abre clockwise-xe1e.local en tu navegador
  3. Ve a la seccion "Caratulas" y sube el archivo JSON
  4. Selecciona la caratula y disfruta
